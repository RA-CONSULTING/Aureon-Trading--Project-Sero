## SECTION 2: TECHNICAL APPROACH (500 words)

### 2.1 Shared Technical Architecture

All four projects share a unified multi-agent architecture:

```
Data Ingestion Layer (50+ sources)
    ↓
AI Processing Layer (multi-model ensemble)
    ↓
Evidence-Provenance Engine (W3C PROV standards)
    ↓
Human Validation Gate (mandatory for consequential actions)
    ↓
Execution Layer (trading, alerts, shield deployment)
```

**Key Innovations:**
- **Evidence-Provenance Tracking:** Every AI output tagged with source, model version, temperature, timestamp, and confidence score. Uses W3C PROV standards.
- **Multi-Model Ensemble:** Queries 3+ models (OpenAI, Anthropic, local LLaMA) and flags contradictions for human review.
- **Human-in-the-Loop Gate:** Configurable authority scope — some actions autonomous, all consequential actions require explicit approval.
- **Local-First Deployment:** All processing on local hardware. No data leaves the machine. GDPR-compliant by design.

### 2.2 Project-Specific Technical Details

**AOIA-Core (AI Runtime):**
- Modular pipeline: Input → Retrieval → Evidence Assembly → Model Query → Provenance Tagging → Contradiction Check → Human Approval → Execution
- Memory Ontology: Structured knowledge graph with versioning and rollback
- Runtime Map: Real-time visualization of data flow and decisions

**AQTS (Quantitative Trading):**
- 3 specialised bots: Trend (1h-4h), Mean Reversion (15m-1h), Arbitrage (real-time)
- Consensus engine: Weighted voting based on recent accuracy
- Risk manager: Kelly criterion, max drawdown, correlation heatmap, VaR

**EDS (Environmental Defence):**
- 50+ data extractors: NOAA solar wind, plasma, Kp index, X-ray flux, geomagnetic field, seismic, atmospheric
- AI anomaly detection: Isolation Forest, LSTM autoencoders, Prophet forecasting
- 24-hour predictive modelling for solar storm arrival
- Severity-graded alerts (INFO → WARNING → CRITICAL)

**EPAS (Electromagnetic Shield):**
- 3-layer design: Passive (Kevlar-Dacron-Mylar, 10g/m²) → Semi-active (stainless steel, 50V bias, 100g/m²) → Active (aluminium honeycomb, 6.35cm, EM cancellation)
- Power: 12V batteries, 57W operational, 5.5h autonomy
- Thermal range: -40°C to +70°C
- Mass: 24.7kg (Class 4) / 12.7kg (Class 2) / 8.7kg (Class 0)

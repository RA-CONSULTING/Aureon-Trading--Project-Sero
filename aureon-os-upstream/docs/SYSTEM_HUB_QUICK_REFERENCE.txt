│                         🔧 TROUBLESHOOTING                                    │
├───────────────────────────────────────────────────────────────────────────────┤
│                                                                               │
│  Problem: No systems showing up                                              │
│  Solution: Run python aureon_system_hub.py to regenerate registry             │
│                                                                               │
│  Problem: Dashboard won't start (port in use)                                │
│  Solution: Kill existing process on port 13001                                │
│            lsof -ti:13001 | xargs kill -9                                     │
│                                                                               │
│  Problem: Missing "rich" library for CLI                                     │
│  Solution: pip install rich  (or it will use fallback tables)                │
│                                                                               │
│  Problem: Can't find my new system                                           │
│  Solution: Ensure filename starts with "aureon_" and ends with ".py"         │
│            Re-run: python aureon_system_hub.py                                │
│                                                                               │
│  Problem: Wrong category assigned                                            │
│  Solution: Rename file to include category keyword                           │
│            (See SYSTEM_HUB_INTEGRATION.py for patterns)                       │

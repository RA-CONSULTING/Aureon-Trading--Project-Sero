WORKFLOW: Market Signal → Neural Thinking → Trade Decision → Outcome → Learning

   ├─ emotional_coherence (market fear/greed)

2. THINK (Forward pass through MLP)
   Input → 6 neurons
      ↓
   Hidden layer (12 ReLU) → learns feature combinations
      ↓
   Output layer (1 Sigmoid) → confidence 0-1
      ↓
   Result: "Should I trade this asset?"

3. TRADE or SKIP based on confidence threshold

4. GET OUTCOME (Win/Loss)

5. LEARN (Backpropagation)
   • Compute prediction error
   • Calculate gradients via chain rule
   • Update weights with gradient descent
   • Record to training history
   
   Result: Queen's brain improves

6. SAVE WEIGHTS
   • Persist to queen_neuron_weights.json
   • Load on next startup
   • Continuous learning across sessions

7. DREAM (Optional: Batch training on history)
   • Review last 100 trades
   • Retrain on full batch
   • Identify patterns
   • Update internal models

TECHNICAL SPECIFICATIONS
═══════════════════════════════════════════════════════════════════════════════════

Neural Network Details:
├─ Type: Multilayer Perceptron (MLP)
├─ Framework: NumPy (no heavy dependencies)
├─ Layers: 6-12-1 (input-hidden-output)
├─ Activations: ReLU (hidden), Sigmoid (output)
├─ Learning: Backpropagation with gradient descent
├─ Loss: Mean Squared Error (MSE)
├─ Learning Rate: 0.01 (adjustable per training)
├─ Batch Size: Variable (supports single examples and batches)
└─ Persistence: JSON-based weight storage

Performance Characteristics:
├─ Prediction latency: < 1ms (per prediction)
├─ Training time: 0.1-1ms (per example)
├─ Batch training: 1-10ms (per batch of 10 examples)
├─ Memory: ~50KB (weights + metadata)
└─ Weights file size: ~3KB (JSON compressed)
